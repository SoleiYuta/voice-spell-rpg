# 音声詠唱評価項目

プレイヤーの詠唱は複数の軸で評価される。評価結果は戦闘に直結し、AIゲームマスターへのフィードバックにもなる。

---

## 評価項目一覧

| 評価項目 | 説明 | ゲーム内効果例 |
|---|---|---|
| **詠唱成功 / 失敗** | 呪文全体を最後まで言えたか | 失敗は魔法不発、クリティカル失敗で反動ダメージ |
| **発音一致率** | 呪文テキストとの一致度（0〜100%） | 一致率が高いほど基本威力上昇 |
| **キーワード認識率** | 呪文の核となる単語が認識されたか | キーワード未検出で効果が半減 |
| **詠唱完了率** | 途中で止まらず最後まで読んだか | 完走でボーナスダメージ |
| **誤認識数** | AIが聞き取れなかった単語の数 | 誤認識が多いと詠唱がブレて属性がランダム変化 |
| **音量** | マイク入力の音量レベル | 大声ほど高火力 / 小声で隠密属性ボーナス |
| **詠唱速度** | 1秒あたりの発話速度 | 早口成功でDPS上昇 / 遅すぎると敵が先制 |
| **感情量** | 発話の感情強度（興奮・落ち着き・緊張） | 興奮状態で火力ブースト / 動揺すると命中率低下 |
| **声の安定性** | 音量・音程のブレ | 安定した詠唱ほど詠唱集中ボーナス |
| **詰まり** | 途中で止まった回数 | 詰まるたびにMP小消費 |
| **言い直し** | 「あ、えーと」など言い直した回数 | 言い直し多いとチャージ時間延長 |
| **息切れ** | 長文後の呼吸検出 | 息切れで次の詠唱に短ペナルティ |
| **羞恥耐性** | 恥ずかしいセリフをためらわず言えたか | 恥ずかしい詠唱ほど高威力（AIが判定） |
| **集中度** | 詠唱開始から完了までの一貫性 | 集中度が高いと全評価に補正ボーナス |

---

## 評価スコアの活用方法

### 戦闘への影響

```
最終威力 = 基本威力 × 発音一致率 × 音量補正 × 速度補正 × 集中度補正
```

各補正値はGeminiが評価スコアをもとに係数を計算する。

### AIゲームマスターへのフィードバック

各評価項目はFirestoreに記録され、AIゲームマスターが次のフロアを設計する際に参照する。

例：
- 「このプレイヤーは音量は高いが速度が遅い」 → 詠唱速度を問う呪文を生成
- 「言い直しが多い」 → 発音の簡単な呪文に一時的に緩める
- 「羞恥耐性が高い」 → より恥ずかしいセリフで高報酬を狙わせる

---

## ユニークな評価軸の設計意図

### 羞恥耐性

- 「恥ずかしいセリフを大声で言えるか」がゲームの核
- 配信映え・笑い・共感を生む
- AIが「このセリフは難易度：羞恥5/5」として設定

### 感情量

- 単なる正誤ではなく、「魔法使いとしての気迫」を評価
- 棒読みより熱量のある詠唱が強くなる

### 息切れ

- 長文詠唱のリスクを可視化
- 高報酬と引き換えに体力（呼吸）を消費するトレードオフ
